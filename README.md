# synquery-agi-autonomous

Synquery AGI（社内 AGI）と Synquery web-platform 製品（当社主力製品と派生製品群）に関する情報発信のためのリポジトリです。

GitHub はデプロイ先ではありません。ここに置くのは、デプロイのためのツールや仕組み、手順書、毎日更新するネタです。

## 構成

| ディレクトリ | 中身 |
|---|---|
| `notes/` | 毎日のネタ。1日1ファイル、名前は `YYYY-MM-DD.md`（JST） |
| `guides/` | 手順書 |
| `tools/` | デプロイのためのツールや仕組み |
| `agi/` | Synquery AGI に関する資料 |
| `platform/` | Synquery web-platform 製品群に関する資料 |

## 公開の基準

このリポジトリは公開されています。`main` に入ったものは外に出たものとして扱います。

**置いてよいもの**
- 公開済み、または公開を決めた機能・仕組みの説明
- 一般化した手順や、汎用のツール
- 実測値。ただし出典と取得日を添える

**置かないもの**
- 顧客名、取引先名、個人名、連絡先
- 内部の構成、ホスト名、認証情報、環境変数、API キー
- 未発表の機能、価格、提携
- 資金、評価額、資本政策、ランウェイ
- 法務・税務・知的財産の検討中の論点、契約の状況
- GTM の現在地スナップショットや未決事項（正の置き場は別にある）

迷ったものは置かない。

## 運用

- 作業はブランチで行い、プルリクエストを経て `main` に入れる。
- `main` へのマージは代表が行う。マージが公開前の確認を兼ねる。
- 事実・確定事項・仮説を混ぜない。仮説には〈仮説〉と付ける。
- 見出し・本文に絵文字や警告記号を使わない。
